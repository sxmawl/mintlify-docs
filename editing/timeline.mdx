---
title: "Timeline Editing"
description: "Arrange, trim, split, and layer clips with the editor's timeline controls."
---

The timeline sits below the preview. Time runs from left to right; higher visual tracks appear above lower tracks in the finished video. Select a clip to open its properties in the left panel.

## Move and trim clips

Drag a clip to change its position or track. Clips use free placement, so moving or deleting one does not guarantee a gap-free timeline.

Drag a clip's edge inward to shorten it or outward to extend it within the available source media. Extending a trim can push later clips forward. Shortening or deleting a clip can leave a gap; click a gap between clips to close it.

## Split and delete

1. Select the clip and move the playhead to the cut.
2. Press **B**, or use **Split at playhead** in the timeline controls.
3. Move or trim the resulting pieces. Select a piece and press **Backspace** to delete it.

These keys use the default Cardboard shortcut preset. If your pointer is over the timeline, the split happens at the hover line. With no clip selected, every clip under that point is split.

## Audio controls

Select a clip with audio to adjust volume and fades in its properties. Volume ranges from 0% to 200%.

- **Mute** in the clip's right-click menu silences the clip.
- **Separate Audio** puts its audio on a separate track so you can edit it independently.

See [Music & Audio](/editing/music-and-audio) for mixing and voice cleanup.

## Layer and transform

Place an overlay on a higher track than the background. Use the preview and clip properties to adjust its position, scale, and rotation. For a picture-in-picture edit, make the upper clip smaller and position it in a corner.

Use the **Text** panel for titles and text overlays. For an animated change in position, scale, or opacity on a video, image, or graphic clip, use [keyframes](/editing/effects-and-transitions).

## Speed, transitions, and color

Select a video clip and adjust its speed in the properties. The speed setting is constant for that clip; split it into sections if you need different speeds.

Open **Transitions** and drag a transition onto a cut between clips. Open **Effects → Color looks** to add a color look. See [Effects, Transitions & Color](/editing/effects-and-transitions).

For a beat-synced edit, ask the agent to align cuts with a music track. You can also listen and adjust the cuts manually; there is no timeline beat-marker control.

## Default keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Play / pause | Space |
| Move one frame | Left / Right arrow |
| Jump to start / end | Cmd/Ctrl+Left / Right |
| Split at playhead | B |
| Delete selection | Backspace |
| Duplicate | Cmd/Ctrl+D |
| Copy / cut / paste | Cmd/Ctrl+C / X / V |
| Undo / redo manual edits | Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z |
| Mute / unmute | M |
| Remove silences | Shift+S |
| Toggle snapping | S |
| Toggle keyframe lanes | U |
| Fit timeline | Cmd/Ctrl+0 |
| Import | Cmd/Ctrl+I |
| Export | Cmd/Ctrl+E |

Shortcuts are customizable. Presets are available for Premiere Pro, DaVinci Resolve, Final Cut Pro, and CapCut. Open keyboard shortcuts from the Cardboard brand menu on the web, or **Settings → Shortcuts** on Mac.

For AI changes, ask in chat to undo or revise the edit. See [How to Talk to Cardboard](/learn/talk).
