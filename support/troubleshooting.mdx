---
title: "Troubleshooting"
description: "Check common upload, export, audio, and editing problems."
---

These checks cover the web editor. For problems in Claude or ChatGPT, see [connector troubleshooting](https://docs.cardboard.ai/mcp/troubleshooting).

## The editor will not open

Use an updated Chrome or Microsoft Edge browser on a computer with WebGL2 available. Safari, Firefox, Arc, and Brave are currently blocked by the editor's compatibility check. The full editor requires a screen at least 1024 pixels wide.

## An export is slow or fails

Web exports can run in the browser or cloud; they are not always local. Long timelines, high resolutions, and complex effects can take longer.

- Check the progress indicator and note any error message.
- Confirm that your media finished uploading and processing.
- Try MP4 with H.264, a lower resolution, or a lower quality setting.
- Close unused browser tabs if your computer is low on memory.
- If you see a plan limit, check [Plans & Pricing](/account/plans-and-pricing) and your usage in Settings.

If the problem persists, [contact Support](https://www.cardboard.ai/support) with the project link, browser, export settings, and error message.

## A file will not import

- Check the [supported formats](/learn/search). A supported extension can still contain an unsupported codec.
- Play the source file in another application to check that it is readable.
- For web uploads, check the per-file limit: 2.5 GB on Lite, Starter, and Creator; 10 GB on Pro.
- If needed, convert a copy to a supported format and retry. Keep the original file.

## Transcription or analysis is incomplete

Check that the upload and background processing have finished. Transcription needs audible speech; noise, overlapping speakers, and very quiet recordings can reduce accuracy. In the captions controls, choose the spoken language explicitly if Auto detects it incorrectly.

If processing reports an error or remains stuck, send the error and project link to [Support](https://www.cardboard.ai/support).

## Audio is missing or too quiet

- Check the affected clip's mute state and volume in its properties.
- Check your computer's output device and volume, and whether the browser tab is muted.
- Click in the editor and start playback again if the browser has blocked audio playback.
- If only an exported file is affected, try MP4 with H.264 and test it in another player.

## The editor feels slow

Close unused tabs and applications, and allow media processing to finish. Use a supported browser. If a specific clip, effect, or timeline consistently causes the problem, include that detail when contacting Support.

## I cannot find my changes

Make sure the correct account and project are open. Web, Mac, and connector projects are separate. Web projects sync to your account; local Mac projects stay in their `.cardboard` bundles.

For an accidental manual timeline edit, try **Cmd/Ctrl+Z**. For an unwanted AI edit, ask in chat to undo or correct it. If work is missing, keep the project and original media and [contact Support](https://www.cardboard.ai/support) before clearing browser data.

## The AI misunderstood a request

Give a specific correction, such as “Trim the first 5 seconds” or “Move the title above the speaker.” Break a large request into smaller steps and preview after each change. See [How to Talk to Cardboard](/learn/talk).

## Still need help?

Visit [Support](https://www.cardboard.ai/support) or email [humans@cardboard.ai](mailto:humans@cardboard.ai). Include the steps that led to the problem and any error text.
